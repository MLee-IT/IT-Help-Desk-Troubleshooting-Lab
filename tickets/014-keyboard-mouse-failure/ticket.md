# HD-014 - Keyboard and Mouse Failure

## Ticket Information
Category: Hardware / Peripherals
Priority: Medium
Status: Open
User: Morgan Carter
Department: Human Resources
Device: Dell OptiPlex 7090
Operating System: Windows 11

## Issue Description
User reports that the keyboard and mouse connected to their workstation are not responding. The computer is powered on and displaying the Windows desktop, but the user can't interact with the system normally.

## Troubleshooting Steps
1. Asked the user when the keyboard and mouse stopped responding and whether any recent changes were made.
2. Confirmed that the computer was powered on and displaying the Windows desktop.
3. Checked the keyboard and mouse cables to confirm they were securely connected.
4. Disconnected and reconnected the keyboard and mouse.
5. Tested the keyboard and mouse using different USB ports on the computer.
6. Confirmed that the USB ports were not visibly damaged.
7. Restarted the computer using the available Windows restart option.
8. Tested the keyboard and mouse again after the computer restarted.
9. Checked Device Manager for any warning indicators related to USB devices.
10. Confirmed that Windows detected the keyboard and mouse after the restart.

## Findings
The keyboard and mouse were initially unresponsive. Both devices were properly connected, but Windows was not responding to the connected USB peripherals. No physical damage was identified.

## Resolution
Disconnected and reconnected the keyboard and mouse and restarted the computer. After the restart, Windows successfully detected both USB devices and restored normal functionality.

## Verification
Confirmed that the keyboard accepted input and that the mouse cursor responded normally. The user was able to interact with the Windows desktop and open application normally.

## Final Status
**Status:** Resolved

## Technician Notes
The issue appeared to be related to Windows temporarily failing to recognize the connected USB peripherals. The keyboard and mouse were reconnected and the computer was restarted. Both devices were detected normally afterwards, and functionality was verified before closing the ticket.
