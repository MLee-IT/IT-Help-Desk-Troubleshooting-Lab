# HD-020 - Low Disk Space

## Ticket Information
Category: Hardware / Storage
Priority: Medium
Status: Open
User: Joran Carter
Department: Operations
Device: Dell Latitude 5420
Operating System: Windows 11

## Issue Description
User reports that the computer is displaying low disk space warnings. The user states that the computer has become slower and that Windows is repeatedly notifying them that the system drive is running low on available storage.

## Troubleshooting Steps
1. Asked the user when the low disk space warning began and whether they had recently downloaded or installed large files or applications.
2. Opened Windows Storage settings to review the available space on the system drive.
3. Confirmed that the system drive had very limited free space remaining.
4. Reviewed storage categories to identify which types of flies were using the most disk space.
5.Checked the Downloads folder for unnecessary files.
6. Checked the Recycle Bin for previously deleted files that were still consuming storage space.
7. Reviewed temporary files identified by Windows.
8. Confirmed that unnecessary temporary files could be safely removed.
9. Used Windows Storagesettings to remove approved temporary files and other unnecessary system files.
10. Emptied the Recycle Bin.
11. Checked the system drive's available space again.
12. Confirmed that additional free space was available after cleanup.
13. Restarted the computer and checked system performance.

## Findings
The system drive had very limited free space. Temporary files, unnecessary downloaded files, and items remaining in the Recycle Bin were contributing to the storage issue.

## Resolution
Removed approved temporary files and unnecessary downloaded files and emptied the Recycle Bin. Additional free space was successfully recovered on the system drive.

## Verification
Confirmed that Windows was no longer displaying the low disk space warning. The computer restarted normally, and the user reported that system performance had improved.

## Final Status
**Status:** Resolved

## Technician Notes
The low disk space warning was caused by unnecessary files consuming available storage on the system drive. Approved temporary files and unnecessary user files were removed, and the Recycle Bin was emptied. Available disk space and system performance were verified after cleanup.
