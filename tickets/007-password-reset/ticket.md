# HD-007 - Password Reset

## Ticket Information
Category: Account / Access
Priority: Medium
Status: Open
User: Riley Freeman
Department: Human Resources
Device: Lenovo Thinkpad T14
Operating System: Windows 11

## Issue Description
User reports that they are unable to sign in to their company account because they forgot their password. The user needs assistance regaining access to their workstation and company resources.

## Troubleshooting Steps
1. Verified the user's identity according to the organization's account verification procedures.
2. Confirmed the user was entering the correct username.
3. Confirmed rhat Caps Lock was not enabled and checked for obvious keyboard input issues.
4. Confirmed that the user was receiving a password-related sign-in error.
5. Checked whether the user's account was locked or disabled.
6. Confirmed that the account was active and available for a password reset.
7. Initiated the organization's approved password reset procedure.
8. provided the user with instructions for creating a new password that met the organization's password requirements.
9. Confirmed that the password reset was completed successfully.
10. Asked the user to sign in again using the new password.
11. Confirmed that the user could access the Windows workstation successfully.
12. Confirmed that the user could access the required company resources after signing in.

## Findings
The user's accpunt was active and was not locked or disabled. The user was unable to sign in because thy had forgotten their password.

## Resolution
Completed the approved password reset procedure and assisted the user with creating a new password that met the organization's requirements. The user was able to sign in successfully.

## Verification
Confirmed that the user successfully signed in to the Windows workstation using the new password. The user was also able to access the required company resources.

## Final Status
**Status:** Resolved

## Technician Notes
User identity was verified before the password reset was performed. The account was active and did not require an account unlock. The password was reset using the approved procedure, and successful workstation and resource access were confirmed before closing the ticket.
