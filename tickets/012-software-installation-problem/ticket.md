# HD-012 - Software Installation Problem

## Ticket Information
Category: Software / Application
Priority: Medium
Status: Open
User: Avery Johnson
Department: Marketing
Device: Dell Latitude 5430
Operating System: Windows 11

## Issue Description
User reports that they are unable to install an approved company application. The installation process begins but stops before completion and displays an error message.

## Troubleshooting Steps
1. Asked the user when the installation issue began and whether the application had been installed on the computer previously.
2. Confirmed that the application was approved for use by the organization.
3. Confirmed that the user had an active internet connection.
4. Confirmed that the installation file was downloaded from the approved software source.
5. Checked the available disk space on the computer.
6. Confirmed that Windows was up to date.
7. Attempted to run the application installer again.
8. Documened the error message displayed during the installation.
9. Confirmed that no other installation or update process was currently running.
10. Restarted the computer and attempted the installation again.

## Findings
The application installer repeatedly failed before completing the installation. The computer had sufficient disk space and an active internet connection. No other installation processes were running.

## Resolution
Restarted the computer and ran the approved application installer again. The installation completed successfully after the restart. 

## Verification
Confirmed that the application appeared in the installed application list and launched successfully. The user was able to open the application and confirmed that it was functioning normally.

## Final Status
**Status:** Resolved

## Technician Notes
The application initially failed before completion. Basic system checks confirmed that sufficient disk space and network connectivity were available. Restarting the computer and rerunning the approved installer resolved the installation issue. The appplication was launched successfully and functionality was verified before closing the ticket.
