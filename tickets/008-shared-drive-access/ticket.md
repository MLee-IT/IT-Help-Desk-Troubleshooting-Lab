# HD-008- Unable to Access Shared Drive

## Ticket Information
Category: Network / File Access
Priority: Medium
Status: Open
User: Lacie Jones
Department: Dell Latitude 5440
Operating System: Windows 11

## Issue Description
User reports that they are unable to access the department's shared network drive. The shared device normally appears in File Explorer, but the user receives an access error when attempting to open it.

## Troubleshooting Steps
1. Asked the user when the shared drive access issue began and whether they had recently changed departments or permissions.
2. Confirmed the computer was connected to the company network.
3. Confirmed the user could access other netork resources.
4. Checked File Expplorer to confirm the shared drive was present.
5. Attempted to open the shared drive and documented the access error.
6. Confirmed the user was signed in with their company account.
7. Checked whether other users in the same department could access the shared device.
8. Verified that the shared drive itself was available to other authorized users.
9. Checked the user's mapped drive connection.
10. Disconnected the affected mapped drive,
11. Reconnected the mapped drive using the approved network path.
12. Tested access to the shared drive after reconnecting it.
13. Confirmed that the user could open folders and access files within the shared drive.

## Findings
The shared drive was available and accessible to other authorized users. The user's mapped drive connection was not functioning correctly, preventing normal access through File Explorer.

## Resolution
Disconnected the affected mapped drive and reconnected it using the approve network path. The shared drive was successfully restored in File Explorer.

## Verification
Confirmed that the user could open in the shared drve, browse folders, and access files normally. The user confirmed that shared drive access had been restored.

##  Final Status
**Status:** Resolved

## Technician Notes
The issue was caused by an inorrect or disconnected mapped drive connection. The shared srive itself was available and functioning normally for other authorized users. Reconnecting the mapped drive restored access for the user.
