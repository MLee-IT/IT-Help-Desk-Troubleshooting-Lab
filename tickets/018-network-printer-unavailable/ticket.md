# HD-018 - Network Printer Unavailable

## Ticket Information
Category: Network / Printing
Priority: Medium
Status: Open
User: Morgan Carter
Department: Finance
Device: Dell Latitude 5430
Operating System: Windows 11

## Issue Description
User reports that they are unable to print to the department's network printer. The printer appears in Windows, but the user receives an error indicating that the printer is unavailable.

## Troubleshooting Steps
1. Asked the user when the printer became unavailable and whether other users were experiencing the same issue.
2. Confirmed that the user's computer was connected to the company network.
3. Confirmed that the network printer was powered on.
4. Checked the printer display for error messages or hardware alerts.
5. Confirmed that other users were able to access the network normally.
6. Checked the printer's status in Windows Settings.
7. Confirmed that Windows reported the printer as unavailable.
8. Checked the printer's network connection and documented its assigned IP address.
9. Used 'ping' to test connectivity between the user's computer and the printer.
10. Confirmed that the printer was not responding to network connectivity tests.
11. Restarted the network printer according to the organization's approved procedure.
12. Waited for the printer tp reconnect to the network.
13. Tested connectivity to the printer again using 'ping'.

## Findings
The user's computer and network connection were functioning normally. The network printer was powered on but was not responding to network connectivity tests. The printer's network connection appeared to be unavailable.

## Resolution
Restarted the network printer using the approved procedure. After the printer restarted, it reconnected to the company network and responded normally to connectivity tests.

## Verification
Confirmed that Windows reported the printer as available. Sent a test document to the printer and confirmed that it printed successfully. The user comfirmed that normal printing functionality had been restored.

## Final Status
**Status:** Resolved

## Technician Notes
The issue was isolated to the network printer rather than the user's computer or network connection. The printer was powered on but was not responding over the network. Restarting the printer restored network connectivity, and successful test printing was confirmed before closing the ticket.
