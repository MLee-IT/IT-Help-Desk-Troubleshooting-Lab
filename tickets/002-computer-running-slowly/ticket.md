# HD-002 - Computer Running Slowly

## Ticket Information

Category: Performance / System
Priority: Medium
Status: Open
User: Taylor Johnson
Department: Human Resources
Device: Lenovo ThinkPad T14
Operating System: Windows 11

## Issue Description

User reports that the computer has become noticeably slow. Applications take longer than usual to open, and the system occassionally becomes unresponsive.

## Troubleshooting Steps

1. Asked the user when the performance issue began and whether any recent changes were made.
2. Restarted the computer.
3. Opened Task Manager to check CPU, memory, and disk utilization.
4. Checked the available disk space on the system drive.
5.Reviewed Startup apps in Task Manager and identified unnecessary applications configured to launch at startup.
6. Checked Windows Update and confirmed the systemwas up to date.
7. Ran a Windows Security quick scan to check for potential malware or other security issues.

## Findings

Task Manager showed high memory usage caused by multiple applications running in the background. Several unnecessary startup applications were also enabled.

## Resolution

Disabled unnecessary startup applications and closed nonessential background applications. The computer was restarted to apply the changes.

## Verification

Confirmed that the computer started normally after the restart. Applications opened more quickly,and the system was responsive during testing. User confirmed that the performance issue was resolved.

## Final Status

**Status:** Resolved

## Technician Notes

High memory usage and unnecessary startup applications were contibuting to the system's slow performance. Startup applications were reduced and nonessential background applications were closed. System performance returned to normal after restarting the computer.
