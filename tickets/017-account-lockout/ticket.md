# HD-017 - Account Lockout

## Ticket Information
Category: Account / Access
Priority: High
Status: Open
User: Casey Thompson
Department: Customet Service
Device: Lenovo ThinkPad T14
Operating System: Windows 11

## Issue Description
User reports that they are unable to sign in to their company account. Windows displays a message indicating that the account has been locked. The user states that they have entered their password correctly but still cannot access the workstation.

## Troubleshooting Steps
1. Asked the user when the account lockout occurred and whether they had recently changed their password.
2. Verified the user's identity according to the organization's account veification procedures.
3. Confirmed that the user was entering the correct username.
4. Confirmed that the account was displaying a lockout message rather than a password error.
5. Checked the user's account status in the approved account-management system.
6. Confirmed that the account was currently locked.
7. Reviewed recent sign-in information for repeated failed authentication attempts.
8. Confirmed that the account did not require a password reset.
9. Unlocked the user's account using the organization's approved account-management procedure.
10. Asked the user to sign in again using their existing password.
11. Confirmed that the user was able to sign in successfully.

## Findings
The user's account was locked after multiple unsuccessful authentication attempts. The user's password did not need to be reset, and the account was otherwise active.

## Resolution
Unlocked the user's account using the organization's approved account-management procedure. The user was then able to sign in using their existing password.

## Verification
Confirmed that the user successfully signed in to Windows workstation. The user was able to access the required comany resources without receiving another account lockout message.

## Final Status
**Status:** Resolved

## Technician Notes
The user's account was locked because of repeated unsuccessful authentication attempts. Identity verification was completed before the account was unlocked. No password reset was required. Successful workstation and resource access were confirmed before closing the ticket.
